# Content Library

**Dump here:** https://claude.ai/artifact/DvufVb7XNUjkStZvAfNpNL

1. Open the link. Talk (mic) or type. Hit **Dump it**. Done.
2. When you want content, open a Claude session on this repo and say **"sort my dumps"**.
3. Ready-to-film pieces land in `library/`, sorted by pillar, each with hooks, a reel script, a caption, carousel slides, a quote card and a Story prompt.

On a run with a clip mic: record a voice memo, then paste the transcript into the box.

The sorting rules are in `CLAUDE.md`.
